# ShopProject — Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Проект представляет отдельную Bootstrap-версию учебного интернет-магазина, созданную на основе предметной области КР №1.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

В проекте предусмотрено локальное подключение Bootstrap из папки `vendor/bootstrap/`.

Используются файлы:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap и используется только для точечной настройки внешнего вида проекта.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница отдельного товара;
- `order.html` — форма оформления заказа;
- `contacts.html` — дополнительная страница контактов;
- `css/custom.css` — собственные стили поверх Bootstrap;
- `js/main.js` — минимальная дополнительная логика формы в modal;
- `images/` — изображения товаров;
- `vendor/bootstrap/` — локальные файлы Bootstrap;
- `README.md` — описание проекта;
- `.gitignore` — исключения Git.

## Реализованные Bootstrap-компоненты

- `navbar`;
- `container`, `row`, `col-*`;
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `form-select`;
- `input-group`;
- `form-check`;
- `breadcrumb`;
- `table`;
- `accordion`.

## Bootstrap-сетка

Для адаптивной раскладки используются классы `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `col-xl-*` и `g-*`.

Карточки товаров перестраиваются в зависимости от ширины экрана без отдельного CSS Grid.

## Самостоятельные доработки

- локальная схема подключения Bootstrap;
- дополнительная страница `contacts.html`;
- дополнительный компонент `accordion`;
- улучшенная структура каталога с Bootstrap-фильтрами;
- расширенные карточки товаров с badge и статусами;
- адаптивные страницы товара и заказа;
- минимальная дополнительная JS-логика формы в Bootstrap modal;
- собственный файл `custom.css` без дублирования Bootstrap.
